## 实现与证据

- 原因：旧 `AudioBridge` 只消费玩家射击与爆炸累计值，敌人发弹和 Boss 激光、冲撞等未产生音效事件。
- `CombatAudioEvents` 记录实际成功发弹、出手和落地事件；弹体同一模拟步就撞墙消失，音效仍只消费一次。未成功分配弹体不发声。非弹体攻击在实际阶段切换时发声，预警期不提前播放攻击声。
- 音效事件最多保留 64 项；音频层每帧消费并合并同类齐射，限制并发、频率和远处音量。静音或暂停消费后丢弃，不在返回时重放。重开清理事件与节流时间。
- 新合成 10 段声音，重做火箭发射、重型爆炸，新增普通敌人、Boss 机枪、炮击、激光、砸地、冲撞、近战和水下声波；[资源与试听](../../../素材/音频/combat-sfx-20261114/README.md)。原脚步声仍不加载、不派发；80 / 120 BPM 两关背景音乐和视频复活规则保留。
- **577 / 577** 逻辑测试通过，含 8 项新攻击音效测试与更新后的补给回归；覆盖机甲真实攻击循环、同帧弹体消失、池满、齐射、敌我区分、近战前摇、两关音效、暂停 / 静音 / 重开和火箭爆炸区分。完整日志见 `tests.log` / `tests.json`。
- 本机已有离线 TypeScript 类型检查通过；**10 / 10** Mac 工具链测试通过。新增音效索引和 WAV 哈希校验，旧音效或缺失音效不可固定交付。
- WAV 格式、时长、首尾样本、无削波、运行资源与源文件哈希一致通过，见 `audio-validation.json`。这些检查不代表手机扬声器听感已验收。
- Windows 原 `.ps1` / `.cmd` 构建入口与依赖锁文件未改；未更改版本号、上传或发布。
