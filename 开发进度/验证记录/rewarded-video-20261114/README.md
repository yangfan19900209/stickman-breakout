# 视频复活接入与验证

2026-11-14，基于 1.0.7；用户确认“可以看10次视频，不是一次性给10个”。

## 已实现

- 第一、第二关的每次挑战最多完整观看 10 条视频，每条只领取 1 次复活机会。已有机会时不能再领取；重开或进入另一关重新计数。
- 删除免费、分享、推荐领取复活。普通分享、首页推荐、游戏圈和邀请回流保留；好友榜继续关闭。
- 广告位为 `adunit-d647515c81ac9f11`。初始化预加载；主动点击显示，失败按一次 load → show 重试。只认当前实例严格布尔 `onClose.isEnded === true`，关闭未看完／未知结果／异常都不发放。
- 奖励绑定当前局次与死亡轮次；重复回调、重开、切关、取消、销毁后的迟到事件不能给新局发奖。
- 玩家看完后返回失败页，主动点击“原地复活 · 满血继续”。广告等待／显示阶段统一隔离输入、计时、邀请弹层和原生按钮；等待可取消，清理失败时保持隔离直至关闭。
- 已领取机会在没有安全落点时保留。原战场、武器弹药、满血、准备与保护逻辑保留；复活通关保存进度但不计最快成绩。
- 浏览器不模拟广告成功。关闭免费入口后，没有可用广告的环境可以重新开始。
