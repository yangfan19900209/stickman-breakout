# 1.0.7 暂时隐藏微信好友榜

日期：2026-11-14。用户要求“先把好友排行隐藏掉”。

## 实际变更

- 发布开关：`ReleaseConfig.friendLeaderboard = false`。首页、暂停、失败和通关页的入口统一显示“个人纪录”。
- 纪录面板隐藏个人／好友切换页签；旧好友切换调用回退到个人纪录；移除当前页面中的好友云端提示。
- SocialBridge 保留冷／热启动邀请解析和去重，但关闭好友权限查询、原生授权、开放数据域访问与成绩上传。
- 本机存档仍使用原 release/local 键；没有修改 `canUpload()` 的环境判定，避免意外切换个人存档。个人最快成绩、分享、推荐、游戏圈保留。
- Windows 原构建入口、PowerShell 脚本、依赖锁和版本号不变。本轮不更新通用方法文件。

## 验证

- 541 / 541 项逻辑测试通过，见 [tests.json](tests.json) 与 [完整日志](tests.log)。新增用例实际实例化 PlatformAdapter，在微信宿主模拟中覆盖旧存档读取、通关保存、邀请冷／热启动、去重、分享，以及所有好友操作均不访问权限与数据域。
- 因首次完整测试等待较久，另以单进程顺序运行隐藏／授权／社交三个相关测试文件，39 / 39 通过；随后完整 541 项测试也正常完成。
- 离线类型检查退出码 0；现有 TypeScript 5.8.2、Creator 类型 3.8.8-121517，并非重新 npm ci 的锁定安装。
- Cocos Creator 3.8.8 Mac 编辑器重新构建微信包成功，编辑器显示完成时间 18:12:19；[构建日志](creator-build.log) 含本次完成标记，入口文件时间新于构建前记录。
- 构建前后输入哈希一致；最终脚本包含关闭的好友榜开关；包结构、AppID、横屏、5 个分包、分享封面通过检查。447 个产物文件已固定复制，ZIP 解压后逐文件哈希一致。
- 本次没有运行微信模拟器或手机 UI 验收；未上传 GitHub、微信开发版本、送审或发布。
