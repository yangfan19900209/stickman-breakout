# 80 / 120 BPM 双曲背景音乐与脚步静音

日期：2026-11-14，源码版本 1.0.7，Creator 3.8.8。本轮实现第一关《土耳其进行曲》、第二关《卡农》，普通关卡 80 BPM、大小 Boss 120 BPM，移除脚步音效。用户认可的 100 BPM 原试听完整保留，文件清单见 `original-100bpm-anchor.json`；不把音色认可扩大为本轮游戏或真机已验收。

## 已实现与验证

- `MusicCue` 消费实际关卡、Boss 激活/生命、暂停和胜利状态，不用镜头距离猜测开战。
- `MusicBridge` 使用独立 Cocos AudioSource，双声部交叉淡化，切换保留拍位置；按章预载两段，离章释放旧音乐，处理静音、遮挡、迟到加载、销毁和失败重试边界。
- `GameManager` 复用原游戏暂停状态同步音乐，避免另建后台状态导致浏览器 blur 后无法手动恢复。原生分享/推荐/视频入口、后台与横竖屏均走统一同步。
- `AudioBridge` 不再加载或派发脚步声；枪、爆炸、受击等原音效保留。微信视频复活的十次规则和隐藏好友榜保留。
- `tests.json` / `tests.log`：**569 / 569** 逻辑回归通过，其中 11 项新音乐测试；模拟音频边界，不代表扬声器或真机已验收。
