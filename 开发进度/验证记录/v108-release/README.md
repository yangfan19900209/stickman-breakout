# 1.0.8 正式交付与版本整理

日期：2026-11-14。Creator 3.8.8。用户要求将当前玩法改动整理成1.0.8正式发布包，并提交推送GitHub；微信平台上传、送审和上线尚未执行。

## 本轮范围

当前玩法沿用上一轮已确认的Boss血量、伤害、单发节奏、闪避、鱼的范围、水母、炮筒、补给、音效、音乐与视频复活。本轮将项目版本、锁文件根版本、游戏内版本和浏览器缓存标记统一为1.0.8，不更改依赖版本或再次调整玩法。详细内容见[更新说明](../../../交付/更新说明/1.0.8-更新说明.md)和[两关配置说明](../../../开发计划/关卡/道具清单/两关配置说明-20261114.html)。

正式目录恢复为 `交付/版本/1.0.8/`，包括微信与Web构建、中文命名ZIP、导入说明、更新说明、manifest和两个平台文件清单。GitHub继续保存源码、资源、文档及校验清单，游戏构建、ZIP和原始截图保留本地。

原来平铺的12个1.0.7目录移至 `交付/版本/1.0.7/历史测试包/`。迁移前后5132个文件路径内相对名、大小和SHA-256逐项一致；原清单内部路径保留历史含义，完整映射见[archive-migration.json](archive-migration.json)，阅读入口见[1.0.7索引](../../../交付/版本/1.0.7/README.md)。没有删除或覆盖旧包。

`.DS_Store`、Creator缓存、账号UI配置和临时改前源码副本不进入本轮提交。Creator账号文件保留本机，退出版本控制；资源及`.meta`完整提交。Git远端已有的两条Mac工作流提交保留，当前改动以非强制方式接到远端main之后。
