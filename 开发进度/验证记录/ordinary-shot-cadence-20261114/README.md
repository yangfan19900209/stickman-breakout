# 单发节奏、敌人行动与 Boss 反馈验证

日期：2026-11-14。版本：1.0.7。引擎：Cocos Creator 3.8.8。以下记录覆盖本轮连续追加的玩法反馈，最终配置以[按路线阅读的说明](../../../开发计划/关卡/道具清单/两关配置说明-20261114.html)为准；旧验证目录与固定包保留当轮数据。

## 最终实现

- 两关小 Boss 均为70血；第一关大 Boss仍为120血，第二关大 Boss由120增至140血。两关大 Boss全场各只召唤一批2名增援，击败增援或换阶段不补召。第二关增援是鱼叉、声波潜水兵各1名、各3血，入场先停顿再完整预警，不掉补给。
- 第一关新增3个炮筒：机械阵地第一块低平台下、运输栈道中段高平台下、封锁哨线入口低平台下。固定普通敌人共35名（近战9、步枪14、盾兵6、炮筒6），加2名Boss共37个，计增援最多39个。
- 第二关4个敌对水草改为纯装饰，原位置仍有水草；同段新增4只3血移动水母。水母追游、收缩预警0.85秒、锁定移动突刺、恢复并至少休息1.4秒，命中1血；预警本身不伤人，不能穿越实体地形。第二关固定普通敌人仍40名（潜水兵22、鱼10、水母4、炮筒4），加2名Boss、3颗锚雷共45个目标，计增援最多47个。
- 普通鱼叉、声波和鱼雷潜水兵每轮仅发1枚。下一轮换位、重新瞄准，完成各自完整预警再发射；轮间休息1.4秒，整组后至少2.0秒。普通鱼叉约2.72秒、声波约2.87秒才会再次发射，遮挡或攻击名额限制可延长。海底炮筒保留三方向追踪火箭，不射鱼叉。声波一枚仍采用侧面重叠、依次放大的三个环。
- 玩家第二关鱼叉／声波／鱼雷开火间隔由0.30／0.36／0.68秒改为0.36／0.43／0.80秒。小潜艇移动声波轮间0.40秒、鱼雷轮间0.46秒；大潜艇鱼雷／炮弹轮间0.50秒、声波轮间0.75秒。伤害和弹速不因此变化。
- 普通潜水兵游动与换高度加快，真实来弹360范围内识别，至少0.10秒反应后尝试侧向或斜向闪避；一次约90距离、持续0.30秒，冷却1.6—1.8秒。闪避使用完整身体碰撞检查，不无敌、不穿墙，锁定后的预警和开枪不会被闪避打断。
- 10只掠食鱼：游动110→150，扑咬625→740；追击范围720→820，扑咬距离480→560；预警0.70→0.60秒，恢复1.15→1.00秒。冲刺行程与扩大后的距离配套，仍可通过侧移或实体岩壁躲避。
- 第二关大 Boss删除向外扩散的扇形圆弧，保留定向激光与直线激光扫射。声波每轮3枚、每招2轮，沿相同三条弹道发射，相邻约27.5度，轮间0.75秒，不错位填缝。招式休息由0.65／0.50／0.40秒缩短为0.35／0.28／0.22秒，原1秒定向预警和1.25秒扫射预警保留。3个部件全拆后只剩船体移动，不恢复已删除的攻击；旧圆弧字段保持为零，供存档／复活快照兼容。
- 第一关小 Boss前火箭箱移到机械阵地入口、盾兵之前；箱后留盾兵、新炮筒、近战与步枪兵。第二关小 Boss前鱼雷箱移到沉船前哨入口之前，箱后留甲板炮筒、潜水兵和鱼。每箱8发，不暗扣弹药；普通敌人可消耗弹药，玩家仍可自主绕行或换武器。
- 第二关小 Boss前条件血包提前到第一块横向甲板右端，在小潜艇激活范围之前。4名普通鱼雷潜水兵的掉落全部取消。第二关只保留3个固定8发鱼雷箱、2个声波箱、2个水下手雷箱，最大补给12件（7箱内补给、4个条件血包、1个小Boss掉落血包）；第一关最多9件。此前指定移除的3处血包、第一关战前血包及靠近坦克的油桶继续保留当前安排。
- 伤害规则不变：玩家对Boss普通2／声波3／火箭5；对普通敌人普通1／声波2／火箭与近战斩杀；敌方枪弹与声波1、火箭／鱼雷2。

完整清单通过运行数据生成：[数量与位置数据](inventory.json)、[地标与表格数据](guide-data.json)。说明提供HTML与Markdown，两关所有敌人、血量、血包、武器和场景物件均按地标描述，不要求读者记坐标或编辑图表。
