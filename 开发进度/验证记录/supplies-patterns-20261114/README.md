- 第一关战前血包 `before-tank`：X=5110 改到4590，地面Y=150；不是向Boss靠近。普通行走隔离验证在X约4545.75拾取并回满，坦克仍休眠，初始激活边界约5260。
- 油桶 `barrel-C1/C2`：5330/5420 改到5930/6020。两桶距坦克初始身体边界127/37，均在155爆炸半径内，不重叠身体；间距90可连锁。隔离验证两桶都爆炸，合计造成约11.41伤害。Boss移动后实际命中随位置变化。
- 第二关普通鱼叉每次2发，单发间隔统一0.23秒，取消上一轮中后段0.18秒及3/4发快速连射。中段连续2轮、后段3轮，每轮换位后重新预警与瞄准；整组结束后恢复完整休息。
- 声波普通攻击中后段3向扇形；炮筒固定3向火箭，不再在鱼叉／声波之间轮换。预警与实际方向共用规则。
- 普通火箭追踪转速0.6弧度/秒，小Boss0.5，大Boss沿用0.48；敌方火箭最多追踪1.25秒，玩家追踪规则不变。普通敌弹上限14、Boss上限18保留。
- 未改敌人血量、数量、第二关道具位置、声波三环素材、玩家手感或已认可关卡锚点。
