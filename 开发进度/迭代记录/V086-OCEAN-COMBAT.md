# V0.8.6 第二关武器、敌人战术与路线

本轮目标来自用户反馈：鱼叉细小、敌人装备和弹体不对应、缺少有效躲避与突进、敌人稀少且关卡短。第一关继续以 [L1-V084-20261110](../../doc/BASELINES.md) 为认可锚点。

## 已实现

| 项目 | 新行为 |
| --- | --- |
| 鱼叉 | 使用独立生成的完整杆身、尖端、尾翼弹体；显示长度从 19 提到 64 世界单位，碰撞核心继续保持公平尺寸 |
| 敌人装备 | 鱼叉、声波、鱼雷各有 4 张完整人物动作；手持外观、实测枪口、弹体类型由同一装备状态决定 |
| 弹体 | 敌我共用鱼叉/声波/鱼雷三类造型与尺寸，以内部灰带区分；清除普通敌人原先杂用的 pressure-bolt、外围圆圈和三重线尾迹。深水弹、Boss 激光/缺口环仍是独立玩法 |
| 攻击 | 前段追踪、后段锁定，再发射与恢复；鱼叉短双发、声波单次封路、鱼雷单发缓转；队长交替突进和三类射击 |
| 闪避 | 近处弹体即将命中才感知，反应 0.14 秒后短移约 77 单位；约 3 秒冷却，仍可受伤，不能取消已经开始的攻击预警 |
| 鱼类 | 原先触发约 400、行程约 244 的失配改为最多 450 触发范围、625 冲速和有界持续时间；锁定后可横向躲开，碰撞后的真实位移扫掠命中 |
| 比例 | 潜水兵固定原画比例，鱼和水草也取消按动作重新归一化宽度；攻击不再放大人物 |
| 长度与编排 | 12,400 → 16,400，敌人 26 → 44（含队长）；新增海沟伏击、船坞外环，6 处实体地形和战后条件补给；Boss 场地同步移至 15,200 |
| 密度限制 | 前段最多 2 名、后段最多 3 名同时预警/攻击；普通敌人在途弹上限 14，沿用 96 槽弹池与近处碰撞查询 |

## 验证与边界

275 项逻辑检查覆盖同装备枪口/弹体、全射程突进命中与闪避、撞墙、敌人反应/恢复、无无敌、固定比例及整关输入通关。实际浏览器用普通按键和只读快照，手机视口 844×390、DPR 2，记录了三种敌方枪械发射、鱼的预警/突进及潜水兵闪避；最终证据见 [V086 验收](../验证记录/v086-verification.json)。

完整路线与第一关分别回归，移动端触控和胶囊布局另行检查。固定浏览器时钟的通关时间与可见弹量用于比较行为，不代表普通玩家平均时长或真机 FPS。微信包为本地构建，未上传发布；iPhone/微信真机仍待试玩。

本轮应用项目默认技能、`game-ai` 与 `imagegen`；技能新增突进射程/行程一致、有限且可受伤的闪避、装备与弹体成套契约，并同步安装副本。
