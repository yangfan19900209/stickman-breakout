# V0.8.13：追击、逃生跳台与触控修正

本轮对应六项试玩反馈。修改前保存 [PRE-V0813 源码检查点](../../历史归档/体验锚点/PRE-V0813-20261111/manifest.json)，V084 体验锚点保持不变。

## 实现

1. 最终 Boss 首次进入战区后持续交战，后撤不会停机、回血或隐藏血条；远距离主动追赶，保留锁定预警、攻击与喘息。能跳过掩体、上台和下台；台沿或箱子的近侧出口空间不足时，会从另一侧下去，保持留给玩家的退让距离。推进边界不能强推身体或激光炮口。
2. 决战区增加三处单向平台，宽 260 / 240 / 260，顶面 260 / 324 / 260。两侧可单跳上台，中间可从任一低台跨上；地面站立通路保留。
3. 回退仍受最远推进距离限制，但后方边界同时约束镜头：背景先停，玩家继续走到画面左沿，实体半宽与画面边缘一致。取消旧竞技场镜头锁点；暂停、重开、受击和空中共用规则。
4. 火箭兵行走时使用现有完整持筒步行帧，步幅随实际位移变化；待机、锁定、开火、受击与死亡继续使用对应动作。
5. 移除滑铲触发、状态、碰撞特例、视觉选择、按钮文案和教程。下＋跳为普通跳跃，保留下蹲、低净空检测与二段跳。旧图集保留历史资源，运行路径不使用滑铲。
6. 陆地摇杆保留力度，斜向输入保持相应横向速度；明确向下扇区才蹲行，并用进入/退出滞回避免抖动。水下仍使用原始二维限长向量。

持续交战后，路段目标、拾取提示及连击文字也按战斗状态避让血条，修复只延长 Boss 激活却遗漏其他 HUD 分支的问题。

- 类型检查通过，322 项逻辑回归全部通过，包含真实碰撞轨迹下的跳台双向可达、Boss 下台、镜头停边和摇杆判定；汇总见 [最终验证](../验证记录/v0813-verification.json)。
- 浏览器使用正常键盘与 CDP 多指触控；调试接口只读，不改血量、弹药、敌人状态或传送。完整交战与刻意保留火箭兵的动画观察分开记录。
- 最终浏览器整关通关，剩余 4 格血；小 Boss 交战约 7.54 秒，大 Boss 约 36.15 秒，最终 Boss 八种攻击全部出现。记录 1169 次战区外交战采样、1274 次持续血条采样与 1236 次完整身体取景采样，应用错误为 0。
- 浏览器真实触控测试中，水平、上斜 45°、下斜 45°的横向速度均为 280；双向、多角度与不同力度由逻辑回归覆盖。火箭兵实际渲染到四个不同步行帧；两关六种界面布局、触控暂停、横竖切换及后退镜头专项均通过。
- 真实移动、上下台和满血首次撤退均保留；没有为展示模式给 Boss 强制不死时间，也未改小 Boss 68 血、最终 Boss 180 血与普通敌人伤害规则。
- Web 和微信本地包重新构建。iPhone 15 Pro 尺寸、安全区与微信系统按钮为浏览器模拟；未进行微信/iPhone 真机测试，未上传发布。
- 微信主包 4,188,943 字节、总包 19,529,402 字节，通过本地包体预算；V084 的四个归档与本轮修改前的 419 个源文件检查点哈希均通过核验。

本轮结合 `game-ai`、`camera-systems`、`input-systems`、`level-design`。杨帆体系修正持续交战状态、镜头可见边缘、陆地/水下输入解释、叠放掩体与宽体下台、删除动作后的完整入口检查；同步结果见 [技能核验](../验证记录/v0813-skill-verification.json)。
