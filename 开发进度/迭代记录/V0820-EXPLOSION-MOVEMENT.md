# V0.8.20：爆炸外围线框与突然慢走

2026-11-12。用户确认问题发生在 iPhone 微信，移动时攻击/不攻击均会变慢；黑框只在爆炸时闪现，未看清框形。[总验收](../验证记录/v0820-verification.json)。

## 原因和改动

V0819 仅删除油桶破碎初帧的方框/叉号。油桶延迟引爆后，正式图片之外仍有黑色冲击圆环、地面椭圆和带黑边的闪光底片；这次完整移除这些叠层，保留七阶段火光、后续烟雾、物理碎片和原伤害。不是重新绘制素材。

移动有两个独立原因：

1. 摇杆原下蹲扇区过宽，向下斜推由 58° 到 60° 即从跑步切为蹲行，速度骤降约 59%，返回时滞回还会保持蹲行。下蹲现改为更接近正下方的明确手势，向侧面恢复时及时退出；故意下蹲和向下跳台仍保留。
2. 普通枪弹每次命中、环境爆炸每次触发，都会短暂停住整个场景。现在靠目标受击动作、击退、粒子和声音反馈，不再连带刹停玩家。移动中的自动刀击同样保持流畅；站定刀击及玩家实际受伤的短反应保留。

## 证据

- 类型检查通过，381/381 逻辑测试。新增斜向偏移、按住射击、下蹲/下跳恢复、普通射击命中、远处双油桶连锁及移动刀击/真实受伤区分回归。
- [实际触屏对照](../验证记录/v0820-touch.json)：在相同 852×393、DPR 3 视口对归档 V0819 和 V0820 输入完全相同的双指轨迹。58°、60°、62°、回到 58° 时，旧版速度为 **280 / 115 / 108 / 115**；新版为 **280 / 280 / 263 / 280**。单走和同时按住攻击结果相同，松手释放正常。62° 保留原有摇杆模拟量，不再额外触发蹲行倍率。
- [爆炸连续帧](../验证记录/v0820-after-no-atlas-webgl1/sequence.png)：18 张从破碎到烟雾消失的画面，实际出现 explosion.0–6 全七帧。使用关闭动态图集和已确认的 [WebGL1](../验证记录/v0820-webgl1.json) 浏览器路径；[原始逐帧数据](../验证记录/v0820-after-no-atlas-webgl1.json)。修改前 [普通浏览器](../验证记录/v0820-before-default/sequence.png) 与 [关闭动态图集](../验证记录/v0820-before-no-atlas/sequence.png) 均能看到额外黑色外圈。
- [第一关正常输入通关](../验证记录/v0820-mobile.json)：普通生命/弹药、只读快照，覆盖两个 Boss、爆炸、结尾和结算；未传送、改血或直接击杀。
- Web 与微信包本地构建成功；[包体](../验证记录/v0820-budget.json)主包 4,189,058 字节，总包 20,443,167 字节，符合既有项目预算，未重新核实平台政策。
- [改前检查点](../../历史归档/体验锚点/PRE-V0820-20261112/manifest.json)与[既有内容核对](../验证记录/v0820-preservation.json)保留其他已调顺内容。

这些证明浏览器输入行为与所测绘制路径改善，不能当作 iPhone 微信真机验收或 FPS 提升。新版微信包需要开发者工具重新生成预览后在手机核对；本轮未上传、未发布，也未重新通关第二/第三关。

## 方法维护

本轮按输入动作映射区分误蹲与模拟量，按性能排查方法分离“行为减速”和“掉帧”，没有在缺少测量时宣称优化手机帧率。更新开发体系中的完整爆炸时间线检查，以及摇杆扇区/全局命中停顿的诊断方法；保留其他任务已同步的素材提示词修改。[技能校验与同步](../验证记录/v0820-skill-verification.json)。
