# V0.8.12 iPhone 横屏布局与推进节奏

根据 iPhone 15 Pro 微信试玩反馈，修正左侧留白和系统按钮遮挡，减少第一关土层占屏，降低小 Boss 耐久并限制无限回退。修改前保存 [PRE-V0812 源码检查点](../../历史归档/体验锚点/PRE-V0812-20261111/manifest.json)，原 V084 认可归档保持不变。

## 实现

- **安全区**：本地 Cocos 3.8.8 的 `sys.getSafeAreaRect(false)` 已返回设计分辨率坐标，旧代码再次按窗口比例缩放。现在直接使用设计坐标，只有浏览器 CSS 安全边距另做一次换算。HUD、触摸命中与摇杆使用同一份规范化边距；同尺寸下安全区延迟变化也会刷新。
- **系统按钮**：顶栏避让微信胶囊及其左侧附加圆形按钮；窄横屏缩短进度条和标签区域，动作按钮仍按物理安全区布局。
- **地面构图**：普通场景地平线由底部 260 / 720 调为 150 / 720，土层占屏约 36% → 21%；Boss 区为 144 / 720。保留地图、纹理、实体高度和跳跃参数，开局镜头将主角放在约 34% 画面宽处，避免被摇杆遮住。
- **入口镜头**：记录实际进入过战区，尚未命中 Boss 也同样适用；短暂退过最终 Boss 激活线时，保留附近战斗的缩放和前视，防止重新进场时镜头尚未拉开而裁掉 Boss。只改变取景，原激活、停火和受伤规则保持。
- **小 Boss**：96 → 68 血，减少约 29%；四种攻击、主动换位、真实跳台追击与伤害规则保留。没有最低存活时间或额外免伤，普通敌人仍为步枪三发、刀/火箭一发。
- **回退**：第一关后方边界随最远实际推进位置向前滚动，保留 960 世界单位的退路，约一屏。行走、跳跃、滑铲和受击后退共用水平碰撞约束；接近边界显示“后方已封锁 · 向右突围 →”。最终 Boss 未击破时保留完整竞技场和入口前 140 单位；击破后只随新的推进更新，不把边界突然推到玩家身上。重开清零，敌人仍使用正常碰撞和追击规则。

## 验证

- 类型检查与 **317 项逻辑回归**通过，包含 DPR 1 / 2 / 3 安全区、原生返回设计坐标、胶囊旁附加按钮、回退碰撞、真实掩体/斜坡落地、Boss 场地例外与重置、入口进出的镜头恢复。
- [两关手机布局](../验证记录/v0812-menu.json)：852 × 393、DPR 3，模拟 iPhone 15 Pro 安全区与微信控件；覆盖延迟接口、刘海换边、窄横屏、横竖屏切换、触摸暂停。注入的是宿主接口，无游戏状态修改。
- [回退专项](../验证记录/v0812-retreat.json)：正常按键推进到约 1,816，再持续向左，停在约 869；边界约 856，加上角色半宽 13。剩 3 格血，暂停恢复后边界保留，并能立刻继续向前。模型另覆盖重开清零。
- [浏览器完整关卡](../验证记录/v0812-mobile.json)和[模型完整关卡](../验证记录/v0812-model-campaign.json)均使用正常生命、弹药、伤害和输入。本次浏览器剩 3 格血通关，小 Boss 交战约 17.0 秒、大 Boss 约 38.3 秒；两者四招 / 八招均有出现，1265 个取景采样通过。重武器集中输出的另一条路线会更快击破，时长不是固定保证。完整招式次数、采样及截图以报告为准，交付汇总见 [最终验证](../验证记录/v0812-verification.json)。
- 地形双向可通行的旧测试现在明确为隔离的几何测试；正式游玩单独检查新增回退规则。正常通关策略只选择可达退路与补给，没有绕过边界。
- [较早整关失败](../验证记录/v0812-campaign-first-attempt.json)保留：自动试玩把已击破小 Boss 残留的激活标记视作仍在交战，漏掉后半段空中躲弹；修正的是正常输入策略，未降低游戏伤害。[镜头修复前的通关记录](../验证记录/v0812-campaign-before-framing-fix.json)则复现了入口回退时的取景问题。只有最后构建后的报告计入交付；小 Boss 四招在持续普通射击的隔离测试及模型路线中覆盖，最终 Boss 八招在模型中覆盖；浏览器保留实际招式次数。携带火箭和手雷快速击破时允许跳过后续招式，不用免伤或最低存活时间强制播放。

Web 与微信本地包已更新。上述手机证据是浏览器模拟，**不是 iPhone 微信真机验收**；未上传或发布游戏。

## 技能维护

本轮组合 `game-ui-ux`、`camera-systems` 与 `level-design` 的适配、构图和关卡边界方法。修正“安全区只换算一次”的引擎契约，补充完整系统按钮组、同尺寸延迟安全区、地面占屏与开局遮挡检查，以及推进边界的物理约束和 Boss 例外。官方技能校验通过，[项目/全局 12 文件一致](../验证记录/v0812-skill-verification.json)。
