# 微信推荐入口 P0 接入记录

日期：2026-11-13。范围：首页手动推荐入口、官方组件接入和异常恢复。工程沿用当前工作区 **1.0.6 / Cocos Creator 3.8.8**；第一、二关开放，第三关保持未开放。对应[设计计划](../../开发计划/功能/WECHAT-EVALUATION-PLAN.md)。

## 已实现的行为

- 微信首页底部排列「纪录榜 / 推荐游戏」，沿用现有漫画封面和图片按钮；浏览器正常模式隐藏推荐入口。原有纪录页内容、分享和选关入口继续可用。
- 进入首页后可后台预载，只有玩家点击才调用官方 `show`。预载已完成时复用；仍在加载时先取消旧实例，在同一次点击内创建并展示新实例，避免并发加载和跨异步点击。
- 请求期间显示可取消等待；展示前 8 秒无响应清理后显示可返回的错误说明。收到官方 show 事件后取消超时，玩家可自由停留。
- 关闭返回 `true` 时显示一次「感谢推荐，继续突围！」；`false` 和缺字段安静返回。主动清理不计推荐结果，不奖励、不替玩家提交、不把推荐当作打星评价。
- 基础库低于 3.8.6、版本未知、缺接口或创建失败显示兼容说明，提供微信评分主页路径；其他游戏功能不要求升级最低基础库。
- 清输入、停计时、隐藏原生游戏圈，持续阻止开始/选关/纪录页/分享按钮；邀请回流等待推荐页关闭后处理。返回前台不推断组件关闭，不自动开始战斗。
- 手动销毁异常时保留输入隔离，提供「重试返回首页」，也接受之后的真实关闭事件。取消、销毁、迟到 Promise 和旧监听不会重新打开页面或误报推荐。
- 横屏四种尺寸检查安全区；等待/错误页旋成竖屏时调整排版和取消按钮，仍可返回。

P1 通关结算轻提示及本机频控**未启用**，按设计等待 P0 微信真机验收。

## 代码与依据

主要实现位于 `源码/assets/scripts/platform/RecommendationBridge.ts`、`源码/assets/scripts/ui/RecommendationPanel.ts`，由 PlatformAdapter、PlatformBridge 和 GameManager 接入；首页布局通过 TitlePoster / HUDController 复用原有美术。

[微信评价与推荐指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/game-evaluate.html)依据用户提供的完整正文和图片核对；星级与文字评价仍由微信评分主页承载。[官方小游戏类型定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)补充核对 Promise、`off`、销毁签名和通用 PageManager 能力。通用 API 的 3.6.7 与推荐回调门槛 3.8.6 分开记录。

本机诊断只包含入口、请求/show 次数、关闭状态三态、错误阶段/数字码，不保存原始错误对象、用户标识或评价正文，不上传推荐统计。

## 微信手机验收步骤

1. 导入本次验收目录中的 `wechatgame`，使用测试账号运行，确认首页只出现固定入口且不会自动打开推荐页面。
2. 点击「推荐游戏」，确认打开官方组件；分别关闭且未推荐、已推荐后关闭，核对返回首页、感谢提示和推荐状态。
3. 对预载中点击、弱网、快速连点、取消等待、前后台切换及横竖屏进行检查；返回后确认游戏圈、纪录榜、分享及开始/选关恢复正常。
4. 用低于 3.8.6 或不支持 PageManager 的环境检查兼容说明；真实 iOS / Android 各完成一次官方页面打开与关闭。
5. 只有上述 P0 验收通过后，再按计划评估 P1 结算轻提示。
