# V0.8.16 轻按满跳、Boss 退路与第二关检查

2026-11-11。依据本轮三个要求迭代，维护源为当前工作区；开发前保存 [PRE-V0816](../../历史归档/体验锚点/PRE-V0816-20261111/manifest.json)，453 个源码、配置、测试和文档文件。V084 已认可归档未覆盖。

## 第一跳与机甲

原来不是起跳前蓄力，而是在松开时把上升速度乘以 0.55，导致轻按跳得低。现在第一跳取消这一削速：地面、土狼起跳和落地缓冲都用原来的 550 起跳速度，不增加跳高上限。二段跳仍需再次按下、只消耗一次空中机会，500 起跳速度和原有松手控制保持；下＋跳的单向穿台也保持。

裁决者整体比例 1.2 → 1，相比上一版缩小 16.7%；身体宽 224、高 264，受击框 224×252，所有帧、脚底和炮口读取同一比例。180 血、普通步枪每发 2 伤害、八种攻击和跳台追击保留。高台加二段跳可向左右越过机甲，专项测试使用实际关卡台面和正常接触伤害。单次第一跳的最高点不能独自证明整段跨越安全，因此不声称任意起跳点都可单跳翻越。

## 第二关对照结果

| 检查项 | 实际处理 |
| --- | --- |
| 敌我同类弹药 | 原先长度相同，但长宽比与命中半径分散在不同调用中。统一鱼叉、声波、鱼雷的长宽和半径；保留归属墨纹。小潜艇弹体 1.15 倍，大潜艇 1.25 倍，尾迹起点随真实长度移动；池复用重置等级。 |
| 最终 Boss 不动 | 原本固定 X，仅 Y 正弦浮动。现在待机/恢复时按玩家位置水平追击并换高度，真实船体扫掠地形和玩家；预警、开火、激光和压力环期间船体停稳。 |
| 后撤与边界 | 记录最远推进，保留 960 单位回退；最终战保留完整场地与入口前 500 单位。镜头和角色使用同一左界，镜头先停、角色走至屏幕边缘。遭遇激活不会因退回入口外失效，血条持续显示。 |
| 被宽体 Boss 堵住 | 船体中心 Y 限制在 315–405，船体边界上、下各保留绕行通道；两侧角落都以真实碰撞验证可从上方/下方游到另一边。 |
| 普通武器打最终 Boss | 基础鱼叉对船体及模块伤害 3 → 4.5，对其他敌人仍 3；声波、鱼雷和深水弹伤害保持。爆炸仍按船体去重。 |
| 小 Boss 战后恢复 | 保留鱼雷奖励，另外必掉一个回血 2 点的血包；满血不自动吃掉，死亡只结算一次，真实支撑上沉降。 |
| 章节特有规则 | 水下二维游动、冲刺、三模式驾驶小潜艇、六模式大潜艇、模块销毁及现有敌人装备/动画保持。没有将陆地重力、跳跃、盾兵或三发击杀直接复制到水下。 |
| 已共用修复 | 两关继续使用既有安全区/HUD、触控、无画面震动和装备/胜利入口。 |

## 验证

- 类型检查通过，343/343 逻辑回归通过。新增覆盖：三种步长下的轻按/长按、二段释放及禁止三跳、真实高台双向越过机甲、海底弹体规格与池重置、潜艇追击/暂停/锁定、上下通道、镜头边界、目标限定增伤和必得血包。
- 第一关正常输入模型通关；手机尺寸浏览器完整通关剩 3 血，大 Boss 从首次命中到击破约 30.03 秒。此为自动操作记录，不代表人类平均用时。
- [实际触控记录](../验证记录/v0816-jump.json)：CDP 16 毫秒轻按与持续按住，从地面 150 均跳到 273.75；峰值上升 123.75，二段机会仍为 1。
- [实际平台记录](../验证记录/v0816-platforms.json)：低台 260 → 高台 348，双指下＋跳后穿过当前台面落至地面 150。
- [第二关模型](../验证记录/v0816-ocean-model.json)：正常血量/库存、50 毫秒决策间隔通关剩 5 血。
- [第二关浏览器](../验证记录/v0816-ocean.json)：正常输入完整路线，潜艇处主动后撤 9 秒再交战，通关剩 4 血；记录船体移动约 932 单位、146 次边缘采样和 263 次预警/开火位置锁定采样。敌我三种普通弹体实际渲染长宽相同，小潜艇三种攻击均出现。
- [潜艇六招与弹体补测](../验证记录/v0816-ocean-patterns.json)：通过正常输入推进，第二阶段暂时停火观察，再击破通关剩 4 血；机炮、扇射、鱼雷、扫射、压力环和激光全部实际出现，大 Boss 鱼雷实际宽 72.5，相比普通鱼雷 58 为 1.25 倍。此停火观察不作为持续火力下的难度证据。
- 第二关后撤脚本的前两次尝试已保存：一次长期留在低位未躲锁线，一次后撤停火后面向左方持续射空。修正的是正常操作策略的角度判断及松火转向，没有提高玩家血量、削弱攻击或编辑运行状态。
- Web 与微信本地构建完成。手机尺寸 Chrome 是模拟视口，不等于 iPhone 15 Pro 微信真机；未上传。
