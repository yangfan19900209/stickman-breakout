# 1.0.5 第二关修正

日期：2026-11-13。按本轮五项反馈修改第二关，独立 1.0.5 交付保留第一关原玩法和美术。共享源码同时有 1.0.6 复活、选关和推荐接入；本轮修复已保留在共享源码中，固定包从改前检查点加本轮修改单独构建，未回退其他任务。

## 实现

| 反馈 | 本次结果 |
| --- | --- |
| 小 Boss 移动卡住 | 追击不再受出生点左右 430 距离限制；按完整潜艇宽高在真实地形上规划绕行，保留绕行阶段，避免在“看见玩家”和“恢复距离”之间反复掉头；移动仍经过实体碰撞。完全无路时按间隔重试。预警锁定和冲撞继续保持方向承诺。 |
| 瞄准镜放大与最终细度 | 锁定动画由屏幕半径 74 收拢到 18，历时 0.36 秒；稳定后主线宽 1.2，中心点变小；缩放不改变屏幕尺寸。 |
| 移动射击腿部不动 | 角色画面和枪口共用移动姿态选择。鱼叉使用已有两帧踢腿，声波枪新增四帧完整持枪游泳，鱼雷枪保留三帧移动循环；连续开火不再覆盖为静态人物。 |
| 大 Boss 普通鱼叉、鱼太小且难以命中 | 大 Boss 机炮改为重型爆破弹，保留鱼雷、声波扇射、激光、扫射与压力环；不再发普通鱼叉。敌对鱼重画为更大的尖齿掠食鱼，共六帧。追击、身体受击框和扑咬扫掠共同调整，支持斜向扑咬，锁定后可躲避，实墙可阻挡。 |
| 统一武器伤害和敌人血量 | 鱼叉 1、声波 2；声波穿透时每个目标均扣 2。普通敌人 3 血，盾兵总计 5 血（其中 2 点对应盾牌阶段）；鱼雷枪作为本关火箭类武器，一发可击败普通敌人或盾兵。移除大 Boss 鱼叉额外倍率，Boss 血量保持原值。 |

| 目标 | 鱼叉击杀次数 | 声波击杀次数 | 鱼雷击杀次数 |
| --- | --- | --- | --- |
| 普通敌人，3 血 | 3 | 2 | 1 |
| 盾兵，5 血 | 5 | 3 | 1 |

爆炸范围改为检测目标实体边缘与可见性，避免大体型目标已被弹体击中，却因中心点超出爆炸半径而不受伤；同次爆炸仍只结算一次。
