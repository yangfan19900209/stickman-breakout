# V0.8.7 粗鱼叉与驾驶小潜艇

用户反馈：鱼叉仍然过细，小 Boss 与普通敌人太像；希望改为有人驾驶的小潜艇。本轮沿用已认可的第二关地图、16400 长度和 44 名敌人编排，第一关以 [L1-V084-20261110](../../doc/BASELINES.md) 为保护锚点。

## 实际修改

| 项目 | 结果 |
| --- | --- |
| 鱼叉 | 重新生成短而粗的实体杆身、弹头、连接环和尾翼，敌我同轮廓；长度 72 世界单位。检查的是杆身截面而非总长度，在 390 高、720 设计高手机视口中至少 4 CSS 像素。伤害核心仍为玩家 4、敌人 5，尾翼不扩大命中范围 |
| 小 Boss | “铁壳号”驾驶潜艇：可见驾驶员、圆舱、双鱼雷管、船首声波口与尾部螺旋桨。替换原先持枪队长的完整轮廓，保留内部 `captain` 标识以兼容关卡和战果 |
| 动作与攻击 | 原地寻高对准，预警后锁定船首朝向；双管鱼雷、三路声波、横向船首冲撞轮换，各自有恢复窗口。船体不随攻击放大，也不沿用潜水兵的全身瞄准旋转 |
| 实际几何 | 源像素比例统一 0.28，逐帧测量枢轴与 3 个炮口。移动占地半宽 96、高 124；可受击船壳 176×108，避开尾翼/空心护罩；冲撞使用实际位移的矩形扫掠，墙体同时阻挡船体和枪口到弹体的路径 |
| 受损与击破 | 低于 40% 生命改用裂纹船壳；击破换残骸，连续两次次级爆破并倾斜下沉后淡出。击杀与掉落仍只结算一次 |

## 验证

282 项逻辑回归通过。浏览器以普通按键、只读游戏快照和固定时钟跑完整路线；第二关在 844×390、DPR 2 视口检查鱼叉、潜艇三种攻击、受损与沉没，另行回归第一关、触控、暂停和胶囊布局。构建包含网页与微信本地包，最终数据及截图索引见 [V087 验收](../验证记录/v087-verification.json)。

试玩策略补充了对仍在飞行的可见敌弹的躲避：击杀敌人不会消除它已发射的子弹。升级武器可能在第三次攻击前击破小潜艇，因此专项试玩会短暂松开攻击、躲避观察三种模式后再反击。此处只改变测试输入策略，未增加玩家生命、隐藏传送或降低敌人伤害。固定时钟通关不代表平均玩家难度或手机帧率；微信/iPhone 真机未测，未上传发布。

本轮结合 `imagegen` 和 `game-ai` 的素材与状态组织方法。技能目录在本轮被更名为“杨帆游戏开发体系”，已按当前入口保留更名后的全部有效规则；新增“杆身屏幕厚度”和“载具轮廓/几何/多炮口一致”经验，同步并校验 12 文件一致。旧版本技能报告保留历史归属。
