# 游戏素材

本目录保存创作来源与美术记录。运营推广图、提审资料和备案截图统一放[运营](../运营/README.md)。

| 位置 | 内容 |
| --- | --- |
| [游戏美术/source](游戏美术/source) | 原稿、生成原图、提示词与来源记录 |
| [游戏美术/slices](游戏美术/slices) | 切片和处理中间图 |
| [游戏美术](游戏美术) 中的 JSON / HTML | 图集清单、挂点、来源哈希与预览页 |
| [说明](说明/README.md) | 美术交付和版本设计记录 |
| [运行资源](../源码/assets) | 游戏真正加载的图片、声音和图集 |

新增素材流程：原稿和提示词进入 `游戏美术/source/` → 使用 `源码/scripts/` 中对应处理工具 → 输出运行资源至 `源码/assets/` → 更新帧表、来源清单与验证记录。清单中的文件路径按工具工作目录 `源码/` 解析；历史证据保留原路径。

不要按文件名中的旧版本号删除素材。当前仍使用多个早期图集；运行资源与 `.meta` 必须成对管理。封闭的第三关样段及其来源保留供后续开发。
