# V0.7.0 第二关《深海突围》首版

[文档目录](../../doc/README.md) · [设计目标](../../开发计划/关卡/LEVEL-02-DESIGN.md) · [源资源](LEVEL-02-ASSETS.md) · [验收报告](../../开发进度/验证记录/v070-verification.json)

本版交付可从悬崖走到潜艇结算的完整第二关，并与第一关结算衔接。沿用黑白漫画风格和现有 Cocos Creator 3.8.8 工程，未上传或发布。

## 试玩与操作

双击项目根目录 [试玩.cmd](../../试玩.cmd)，或打开 [本地游戏](http://127.0.0.1:4190)。首页“第二关”直接进入；第一关胜利后主按钮也进入第二关。新章节从满生命、基础声纳和三枚深水弹开始；暂停菜单可返回首页。

| 操作 | 电脑 | 手机横屏 |
| --- | --- | --- |
| 游动 | WASD，支持斜向 | 左摇杆自由游动 |
| 普攻 | J | 普攻按钮，可边游边打 |
| 短程推进 | Space | 推进按钮，有冷却 |
| 深水弹 | K | 深水弹按钮 |
| 切刀/切回炮 | Q | 顶部武器栏 |
| 暂停 | P / Esc | 右上暂停 |

走到悬崖边自动换装、跃水；首轮播放完整入场，再战可按 Enter 或点击跳过。水下会自动瞄准前方可见敌人，瞄准与游动方向独立。贴近安全密封箱按普攻自动用刀，整次按住都保护有限弹药。

## 已实现范围

- **路线：**12400 单位，与第一关宽度相同。包含浅海训练、水草暗礁、沉船前哨、重装潜水队长、深水断层、潜艇防线、战前整备和潜艇战。13 处实体障碍、局部洋流、22 名敌人/危险目标、7 个补给箱；漏敌不会设置隐形封路。
- **武器：**无限声纳、可穿透的聚能声纳、有限转向鱼雷、延时下沉深水弹和刀击。声波每个目标每次最多伤害一次；鱼雷使用完整持用姿势的真实炮口，末发耗尽后的画面仍保留该次发射姿势。
- **敌人：**潜水射手、锁线冲刺鱼、固定攻击水草、炮台、水雷和重装潜水队长。预警后锁向/出手，保留恢复机会；水雷有可见系缆，固定敌人根部与真实支撑面一致。
- **补给与物理：**自由二维移动、斜向限速、推进和实体阻挡。箱子/残骸/掉落缓慢下沉到实际支撑面。四个医疗候选点只在缺至少两格血且附近无同类掉落时生成，每点每局至多一次。
- **潜艇：**三阶段，锁线机炮、扇形炮、有限转向鱼雷、固定激光、半区扫描和缺口压力环；炮/激光/鱼雷部件可破坏，损坏后对应攻击停用。爆炸覆盖多部件不会重复放大总血量伤害。
- **结算：**清除敌弹和伤害后，连锁爆炸、潜艇倾斜沉没、震屏/震动请求、人物上浮拉近欢呼，再显示结算。暂停、重开和返回首页恢复对应状态。

## 工程与资源

[OceanSession](../../源码/assets/scripts/ocean/OceanSession.ts) 独立持有水下状态，[OceanLevel](../../源码/assets/scripts/ocean/OceanLevel.ts) 定义路线；[GameManager](../../源码/assets/scripts/GameManager.ts) 管理章节加载和会话切换。输入保留纵向模拟值，复用 HUD、碰撞算法、玩家生命、镜头及胜利时间线，第一关没有改为无重力模式。

[OceanPose](../../源码/assets/scripts/ocean/OceanPose.ts) 定义完整持炮姿势的身体枢轴与枪口，`bossModuleTransform` 统一炮塔旋转与发射点；[OceanRenderer](../../源码/assets/scripts/ocean/OceanRenderer.ts) 消费模拟状态绘制。原画与身体旋转使用同一坐标变换，避免先从人物前方出弹再向上转弯。

[pack-level02.py](../../源码/scripts/pack-level02.py) 从保留的切片生成 115 张运行图片，完整组装潜艇只作参考而不打包。大型船体/地形保留原尺寸，其余精灵减半并量化为 128 色；背景转 1280 宽 JPEG，明确属于有损运行副本，原图/切片不变。[运行清单](../游戏美术/level02-runtime.json)记录来源、尺寸和哈希。新增声纳与水下爆炸两段合成音效，其余复用现有声音。

章节通过 `assetManager.loadBundle('level02')` 预载纹理后进入。微信使用项目 `bundleConfig.custom` 与目录 `bundleConfigID`，`game.json` 中存在 `level02` 分包；保留 `resources` 和 `main`。具体字节数和文件指纹以[验收报告](../../开发进度/验证记录/v070-verification.json)为准，主包遵守本项目既有 4 MiB 预算，不能据此宣称符合未来所有平台限额。

最终自动通关时间和分段血量保存在验收报告。此前不同轮次第一关约 79–107 秒、第二关约 73–75 秒，自动操作对局会有变化；宽度一致且都有中段首领和后半程遭遇，但不将单次计时当作人工游玩时长或难度的定论。

这是第一版：地形仍为明确实体轮廓配局部原画装饰，尚未完成自然地形连续拼接；角色使用关键姿态与有限踢腿帧，更多过渡/装备移动帧需后续完善。补给剪断系缆、完整水下环境音、潜艇巡航位置变化及弱点倍率等设计细节尚未接入。六种攻击的模型行为已覆盖，实际通关会随部件破坏跳过部分招式，不能将一次通关截图视为每种攻击都已独立人工验收。

游戏技能已补充章节状态边界、纵向输入、末发弹药姿态、章节分包配置和有损运行副本的经验；同步校验见[技能维护记录](../../开发进度/验证记录/cocos-2d-action-games-skill-verification.json)。
