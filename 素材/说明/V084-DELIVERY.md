# V0.8.4 生成漫画按钮与动作图标

本轮针对按钮简陋、动作图标不直观与 UI 画风不统一的问题。最终控件使用内置 image_gen 生成的黑白粗线图片；金属/写实候选不参与运行时构建。

## 实际变化

- 第一关跳跃是戴帽主角跃起；二段跳有第二次起跳标记，滑铲有低姿态人形。第二关冲刺使用横向箭头与速度线，按钮和入水/暂停说明同步“冲刺”语义。
- 攻击、手雷、切刀、摇杆、暂停、数量徽章与菜单按钮同属一套生成美术。代码保留原生文字、布局、按压、禁用、冷却和触摸；不再自行绘制最终按钮或图标。
- 12 张完整素材共用预载图集，摇柄移动只变换 Sprite；数量角标处于冷却层上方。按钮显示按压不缩小输入节点，原胶囊避让规则保留。
- 菜单底板使用实际圆角范围的九宫格切线，并校正源图到 UI 比例；实际检查最矮按钮的黑边与文字净空。

## 维护规则

已把用户明确要求写入项目 skill 并同步全局副本：操作美术用生成图片，不用程序拼画替代；以现有角色与实景为风格参考，拒绝写实金属材质；不同移动动作需要独立图标；原生代码只管理状态与交互。新增了资源留白、角标层级及菜单圆角缩放的验收方法。
