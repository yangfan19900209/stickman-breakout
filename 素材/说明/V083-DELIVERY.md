# V0.8.3 举枪步态、滑铲与操作反馈

2026-11-10。本地 Web 和微信小游戏构建，未上传或发布。

## 本轮行为

- 步枪、火箭筒各补齐斜上和向上持枪的四帧完整步态；移动与开火共享步态及该帧实测炮口，切换方向不会恢复成静止举枪图。
- 陆地增加滑铲：手机摇杆向下＋跳跃，键盘 S＋Space。动作持续 0.44 秒、冷却 0.78 秒，沿起始朝向低姿态移动。墙体与箱子真实阻挡，离台结束滑铲，头顶被挡时保持低姿态；受伤中断，暂停冻结，重开清零。
- 地面组合先于普通跳跃解析；空中再次点跳仍为二段跳。水下沿用自由游动和推进，不套用滑铲。
- 持枪近身拆箱有完整挥刀动作和有效期刀光，蹲下也有低位切割姿态。整次拆箱按压仍保护有限弹药；不增加第二把叠加的刀。
- 受击后仰优先于瞄准和持枪分支，配合命中星芒、短促镜头停顿/震动、生命栏和屏幕边缘提示；受击帧期间禁止从空手姿势发弹。第二关的持鱼雷枪/鱼叉状态也能显示受击图。
- 暂停、摇杆、跳跃、攻击和手雷统一为黑白平面控件，保留原触摸尺寸与微信胶囊避让。跳跃键按实际状态显示二段跳、落地恢复或滑铲，首页、开局和暂停页均有操作说明。
