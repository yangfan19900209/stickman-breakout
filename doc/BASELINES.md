# 已认可的体验锚点

## L1-V084-20261110 — 第一关体验基准

2026-11-10，用户明确反馈：**“这个版本的第一关已经体验不错了。”** 当时运行版本为 **V0.8.4**。这条确认针对第一关的整体体验，不能推定第二关也已获认可。

本轮优化前已保存当前工作区，而非只记录落后于工作区的 Git 提交。基准保留：

- 第一关地图、碰撞与升降台、移动/跳跃/滑铲参数。
- 敌人和两个 Boss 的节奏、关间长度、火箭与手雷补给规则。
- 全套角色、地图、漫画按钮图片和动画资源。
- 同时操作、短按/长按、暂停与屏幕旋转的既有交互。

后续迭代以此对照：没有明确玩法变更要求时，优先修正可复现遗漏、反馈错误和测量确认的重复工作；新的 skill 用来补足方法，不构成重做画风、引擎、第一关难度或手感的理由。
