# 性能与移动平滑

## 先拆开问题

记录设备、运行容器以及触发负载：刚进场、移动、敌人密集、弹幕或爆炸。将逻辑 CPU、绘制调用、纹理内存和动作连续性分别测量。保存改动前基线，用相同输入、碰撞几何、敌人数、弹体数和视口对比；预热后记录中位数、p95 和极值。压力夹具需标明人为设置，正常输入整关回归另行记录。

Node 的逻辑毫秒不能换算为手机 FPS；虚拟浏览器时钟适合流程和每帧绘制调用计数，不能证明真实帧率。模拟小游戏引擎配置也不等于微信真机。不得靠削减敌人、删除已接受的环境动态或改变画风冒充性能修复。

“走路突然变慢”还可能是行为减速而非掉帧。同步记录摇杆原始轴、消费后的轴、蹲姿、实际速度、受击状态、命中停顿和模拟时间；用同样的真实触摸轨迹对比改前/改后，分别覆盖只走路与同时攻击。斜向扇区切换要检查进入与退出阈值，避免误触蹲行后靠滞回持续锁在低速。全场命中停顿会同时暂停无关角色的移动；普通远程命中和远处连锁爆炸优先使用目标局部受击、碎片及声音，移动近战也不应每刀刹停。刻意的受伤反应、站定重击与暂停单独保留和验证。

共享输入入口不代表各章节共用反馈逻辑。复查每个会话的命中、击杀、连爆、Boss 落地与部件销毁入口，以及外层主循环是否把其反馈变成全场停顿；远处 Boss 落地不能意外暂停正在走路的健康玩家。玩家受伤停顿应根据真实扣血单独触发，不能被同帧普通命中的限频吞掉。自由游泳或飞行需比较二维速度长度，斜向的水平分量变小本身不是减速；另外区分设计中的水流、惯性、真实碰撞与意外暂停，保留已有规则。

## 保留精确碰撞，缩小候选范围

从原画轮廓采样的地形可能包含数百个碰撞条带。不要让每个敌人、弹体、视线和掉落支撑每次都扫描整张地图。静态地形可以初始化一次网格或其他空间索引，查询移动扫掠包围盒后继续使用原有精确判定。

- 索引不能漏掉弹体半径、端点接触、反向长射线或高速推进；跨网格矩形去重并保留确定的同距顺序。
- 如果移动包含初始嵌入恢复，查询范围须包含完整恢复距离及邻接实体并集。只查询当前位置的小框会改变脱离结果，可能再次锁死甲板边缘。
- 动态掩体/平台单独纳入候选；不可把会移动的几何永久放入静态索引。复用查询缓冲，避免为每次移动复制整个实体列表。
- 用固定种子的差分测试对比索引候选和全量扫描：最早命中时间、最后坐标、四面接触、邻接角点及高速位移。再回归真实关卡输入路线。

## 按实际平台选择图集合批

先检查当前引擎源码和运行配置，再判断图集是否会降低绘制调用。浏览器的动态图集可能已经合并小图，额外预打包反而可能分裂批次。Cocos 3.8.8 的本地实现中，小游戏默认清理图像缓存，动态图集随之关闭；这是已核验版本的行为，不是所有版本的永久假设。

对缺少动态图集的平台，可把频繁一起出现的敌人、角色、弹体和爆炸打包为静态图集，并按纹理路径去重预载。保留帧 ID、逻辑尺寸、锚点和原始像素，准备采样间距/边缘挤出。核对解码后的逐像素一致性、实际绘制调用、纹理绑定、包体和显存；有更好的原生合批时继续使用原路径。

HUD 向量图形按可见变化缓存：生命变化、进度条跨越一个显示像素、章节或布局变化才重建。章节往返和横竖屏必须使缓存失效。动态鱼群、气泡、预警和攻击继续按游戏时钟更新，暂停时保持一致。

Boss 血条同样要检查：每帧重建矩形即使画面不变也会反复生成几何。缓存包含遭遇对象身份、当前/最大生命、显示尺寸与样式，换敌人、重开或重新布局失效；隐藏时不绘制。攻击预警和阶段文案独立更新，不因血量未变而冻结。用实际运行的重建次数和可见更新机会对比，同时确认受伤后立即更新。调用次数减少只证明消除了重复工作，不等于证明 CPU/GPU 主瓶颈或真机 FPS。

通过浏览器覆盖计数分析引擎模块时，偏移必须对应实际执行脚本。打包器可能以字符串注册或执行模块，磁盘文件是包装文本；按调试协议的 script ID 读取执行文本再定位分支，保留原始计数与普通输入路线。不要将测量脚本的失败误归因于游戏。

使用生成图片的触控 UI，先预载共用图集，再复用 Sprite 和帧表；摇杆底座与摇柄拆成两个节点，移动仅改变摇柄变换，不按坐标变化重新加载或绘制材质。冷却可用引擎原生径向填充裁剪现有图片；按压改变显示子节点，保持触摸节点尺寸固定。检查静止和连续拖动时资源/表面更新次数，不能据此声称真机帧率已经验证。

## 固定步长与显示插值

固定步长物理直接显示在不均匀的渲染帧上，匀速运动仍可能以不等距离跳动。在每个物理 tick 前记录前一姿态，渲染时用剩余时间比例插值人物和镜头；各场景层必须使用同一显示镜头。显示视图只读，不能把插值坐标写回碰撞、瞄准或伤害状态。

保持原型 getter（装备、动画等）有效，复用显示视图。暂停、命中停顿、重开、传送与胜利镜头要重置或直接采用当前姿态，避免回退/拖影。验证不均匀帧间隔下的匀速位移以及模拟状态不变。转向减速时，步行相位依据实际位移长度推进，不能仅乘新朝向导致尚未减速完成的脚步倒放。
