## 1. 核心体验与衔接

第二关潜艇被击败后，主角上浮登上接应甲板，卸下潜水装备，背上双喷口火箭飞行器，携步枪起飞，穿过沿海城市上空与空中运输防线，最终击落指挥飞艇。

主角沿用前两关身份、黑白漫画轮廓和武器比例。天空以浅灰蓝、远处城市与云层提供层次，喷焰采用少量既有暖色强调。飞行时身体直立或小幅前倾、双腿迎风摆动；加速、制动、受击和闪避都有可见姿态变化。

核心循环：**观察敌方预警 → 上下换位或短喷闪避 → 抓恢复窗口射击 → 拾取补给 → 向右推进。** 空战特点来自快速起停、编队入场、俯冲掠袭和绕过空中结构。

开场目标 5–7 秒：登甲板 → 穿戴飞行器 → 喷口试推 → 起飞 → 开放控制。首次完整播放，重试可跳过；跳过与正常播放得到相同位置、生命、装备和输入状态。演出期间敌人不攻击，暂停恢复不重复发装备。

## 2. 飞行、瞄准与手机操作

| 项目 | 初版规则 |
| --- | --- |
| 普通飞行 | 上下左右自由移动，斜向按向量长度归一化；松手快速制动并悬停。普通飞行持续供能，不增加燃料倒计时和松手坠落。 |
| 机动手感 | 原型速度从约 300 单位/秒起调，稍快于前两关 280；起步与反向及时，松手制动目标约 0.1–0.15 秒，以手机操作实测为准。 |
| 喷射闪避 | 原跳跃按钮位置改为“闪避”；沿当前摇杆方向短喷，摇杆中立时沿角色朝向。起调值约 640 单位/秒、0.18 秒、冷却 1.8 秒，按下触发一次。碰墙停止，不穿墙，不额外赋予全程无敌。 |
| 触屏布局 | 左侧摇杆；右侧攻击、闪避、空爆弹三按钮，武器栏切换。保持现有安全区与微信系统按钮避让，不新增必须用第三只手操作的瞄准杆。 |
| 瞄准和转向 | 采用可见范围内的辅助瞄准。优先当前可见目标，离开视野、死亡或被实心障碍挡住时解除；新目标有切换缓冲，避免枪口来回抖。目标在身后时可平滑转向，不把松火转身设为唯一换向方式；松开攻击时由水平移动确定朝向。需实测与移动、闪避并用时不会误锁身后小兵。 |
| 键盘 | WASD 移动、J 攻击、空格闪避、K 空爆弹、Q 切刀，继续走同一输入动作链。 |
| 地形 | 屋顶、天桥、运输机甲板等实体阻挡；云朵与远景不碰撞，不完全盖住敌弹。上下绕行通道至少容纳完整飞行姿态和机动余量。无需跳跃才能跨过平台。 |
| 相机与边界 | 前视不跟随朝向翻转，保留无画面震动；纵向使用稳定区域，避免每次微调高度都拖动背景。回退到边界时镜头先停，玩家再到屏幕边缘。上下可飞范围通过可见场景/气流边缘提前提示，不做无提示坠死。 |

飞行器推进与武器导弹弹药分开命名：HUD 展示生命、武器弹药、空爆弹数量、闪避冷却和关卡进度，避免让人误以为发射导弹会耗尽飞行能力。空爆弹数量沿用按钮角标。

## 3. 武器与补给

| 项目 | 初版方案 |
| --- | --- |
| 基础武器 | 无限弹药突击步枪，沿用约 0.22 秒射击间隔；普通敌人先按三发击杀，装甲敌人多两点生命。 |
| 强武器 | 有限追踪火箭，沿用既有火箭家族，初版装填容量 6；提前布置在两次 Boss 战前。追踪有转向上限，不能绕过实心障碍后继续穿墙命中。 |
| 近战 | 武器栏切刀和近处箱子的弹药保护保持；普通敌人可一刀击杀，但不设计必须贴身破防的主路敌人。 |
| 空爆弹 | 复用手雷按钮与有限库存，初版 3 发、容量 6。沿瞄准方向投出并定时空爆，用于成组敌人；明确爆点反馈，空中没有地面也可生效。具体引信/半径在原型中调整。 |
| 弹体统一 | 玩家、普通敌人使用共同的子弹/火箭规格；小 Boss ×1.15、大 Boss ×1.25，显示、枪口和命中规格共用。避免第三关另建一套不兼容尺寸。 |
| 掉落 | 空投补给装置带降落伞或小推进器，在可达飞行带内缓慢移动/悬停；不得让血包坠入不可达的下方。重开、暂停、重复死亡事件与池满重试均需处理。 |
| Boss 战后 | 小 Boss 必得一个回血 2 点的血包，满血保留；与按缺血条件提供的辅助恢复分开。清楚展示奖励，避开尚未消散的敌弹弹道。 |

Boss 伤害按目标单独调，基础枪必须可完成两场战斗。不能为了让 Boss 耐打同步增加所有杂兵血量；也不以无敌锁血强迫玩家看完全部招式。

## 4. 关卡路线与节奏

先用比例确定经历，原型验证飞速、镜头与避让距离后再落到世界坐标。完整关卡长度初步参考前两关 14800 / 16400，约 16000 单位只是起调值；熟悉操作后的有效战斗/推进时长以同一玩家前两关的约 ±15% 为目标，不把自动脚本用时当成人类平均时长。

```mermaid
flowchart LR
    A[甲板起飞] --> B[屋顶巡逻]
    B --> C[阵风与绕行]
    C --> D[拦截直升机]
    D --> E[回血与喘息]
    E --> F[空中运输线]
    F --> G[堡垒外围]
    G --> H[战前整备]
    H --> I[指挥飞艇]
```

| 进度 | 区段 | 本段体验与节奏 |
| --- | --- | --- |
| 0–8% | 甲板起飞 | 无伤学习上下移动、悬停与闪避，再遇单个慢速射手。 |
| 8–23% | 屋顶巡逻 | 屋顶与天桥形成宽阔上下路线；先步枪敌人，再加入单个掠袭目标。 |
| 23–34% | 阵风通道 | 小范围气流有方向提示，普通速度可逆流退出；先空场试飞，再组合少量空雷。关键路线不要求冷却中的闪避。 |
| 34–43% | 小 Boss 空域 | 进入前提供准备区，单独对战拦截直升机；无普通敌人同时夹击。 |
| 43–50% | 补给缓和 | 必得血包和武器补给，先留喘息与拾取空间，再出现下一组敌人。 |
| 50–72% | 空中运输线 | 运输舰甲板、上下通道和投弹敌人；用短分路提供可选奖励，随后汇合。 |
| 72–86% | 堡垒外围 | 练习锁定导弹、装甲无人机、激光预警；每轮只组合已学过的应对动作。 |
| 86–90% | 战前整备 | 先看到指挥飞艇轮廓，血包/火箭补给在激活范围之外，能够安全取得。 |
| 90–100% | 指挥飞艇 | 宽阔竞技空域，上下均能绕过机身，三阶段战斗后坠毁、主角降落欢呼与结算。 |

普通遭遇同时攻击先限 2 名，后段最多 3 名；全场可见敌人不等于全部同时开火。普通杂兵可绕过，完成关卡需要击败两名 Boss。小 Boss 战斗区通往后续区域的前方出口用**可见防空闸门**标识，击败后解除；闸门位于完整竞技空域以外，不挤占换边通路。

Boss 前的缓冲要大于邻近普通兵的实际感知/追击距离，普通兵巡逻区不越入 Boss 专用空域，不在玩家面前突然删除敌人。后续杂兵保留在待生成队列，不进入渲染/受击列表；击败小 Boss 后至少留出约 3 秒、并待玩家继续推进到下一组的安全入场距离再生成，血包可拾取状态必须先成立。

## 5. 敌人组合

| 敌人 | 玩家读到的信号 | 应对与恢复窗口 |
| --- | --- | --- |
| 喷气步枪兵 | 减速悬停、枪口锁线后短连射 | 上下换位；连射结束后有停火窗口，移动有完整喷气姿态。 |
| 掠袭无人机 | 显示横向或斜向突进路径 | 离开路径或闪避，掠过后明显减速掉头，不瞬间反向撞人。 |
| 导弹飞行兵 | 发射器亮起并显示锁定提示 | 横向拉距、切换高度或绕实体掩体；同时在途导弹数受限，追踪不是必中。 |
| 装甲无人机 | 正面盾牌清晰可辨 | 总生命 5，破盾有碎裂动画；侧面可攻击，保持至少一种基础枪打法。 |
| 投弹机 | 先在下方标出投弹带 | 向旁边或上方绕，投弹后给接近窗口。 |
| 空雷 | 明确轮廓和触发警示 | 可击破或绕过；首次出现时不与强侧风/导弹同时压迫玩家。 |

首个可玩样段只接入步枪兵、掠袭无人机和小 Boss 的核心动作，其他敌人分阶段增加。

## 6. 两场 Boss 战

### 小 Boss：拦截直升机“猎隼”

中等体型、恢复期间主动追击并上下换位。四种动作：

1. 锁高度短点射：枪口预警后固定射击带，上下离开即可。
2. 双导弹：两侧发射器分别出弹，数量有限且有追踪上限。
3. 水平掠袭：提前显示通道，锁定方向后高速掠过，终点制动再掉头。
4. 斜向俯冲：锁定斜线，冲过后停火恢复，避免连续贴身追撞。

基础枪普通操作下交战先以约 15–22 秒为调优目标；初始耐久可从约 64–72 点、基础枪单发 1 点试起（以 0.22 秒间隔持续命中，理论约 14–16 秒），再按实际命中率调整。生存时间要允许看到不同应对动作，不能靠海量血条延长。

### 大 Boss：空中指挥飞艇“苍穹号”

以较宽机身和两个武装模块形成压迫感，尺寸受手机**实际可见战斗区域**限制。初版可见宽度先控制在战斗视口约 35–40%，高度约三分之一；实体上下至少留完整角色加闪避余量。不能只检查中心是否位于边界内。

六种行为按阶段组合：锁线机炮、分组导弹、带空隙的投弹封路、锁线激光、短距离横向压迫、局部风压。前半关提前教会对应的躲法。风压先显示气流方向，可用普通移动逆向离开，不和无退路弹幕同时叠加。

- 第一阶段用机炮/导弹建立节奏；第二阶段组合投弹/激光；第三阶段缩短恢复并加入横向压迫和风压，仍保留独立预警。
- 移动只在允许追击/换位的状态推进；锁线和持续射线期间固定发射源。冲锋则锁定路径与终点，采用实际扫掠伤害。
- 被击破的模块停止对应攻击，机身仍保留可理解的剩余动作；模块伤害与总血量按同一命中事件结算，爆炸不能重复扣总血量。
- 小、大 Boss 一旦激活，后撤不重置遭遇、血量或血条。活动边界考虑完整身体和玩家退路，碰障碍会绕行或恢复，不能变成静止靶。
- 首版不叠加无限杂兵。基础枪约 25–40 秒实战交战为待测目标，三阶段不额外增加三条独立生命。

## 9. 分阶段执行与验收
