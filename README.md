**Windows 试玩：** 双击 [试玩.cmd](试玩.cmd)。第二关独立检查使用 [第二关测试.cmd](第二关测试.cmd)。

**Mac 开发：** 双击 [Mac开发.command](Mac开发.command)，首次选 `1` 初始化并验证；之后可选择测试、Web 试玩、微信构建、固定打包或上传开发版本。构建直接调用 Creator 命令行，无需先打开编辑器窗口。命令用法及本机验证边界见 [Mac 开发说明](doc/MAC-DEVELOPMENT.md)。

**继续开发：** 在 Creator 中打开本项目的 **`源码` 文件夹**；开发命令也在该文件夹执行。依赖已随源码目录迁移。

**获取当前包：** [交付目录](交付/README.md)。固定构建与压缩包保存在本地；GitHub 保存完整源码、运行资源、源素材和文档。缓存、运营提交资料、原始验收截图和大体积历史归档不随源码上传。

`docs/` 是 GitHub Pages 既有生成目录，仍为 0.5.9 历史快照，不是当前微信交付入口。

新增资料按上表存放。任务安排写“开发计划”，完成证据写“开发进度”；游戏运行时用的资源必须和 `.meta` 一起保留在 `源码/assets/`。根目录不再堆放原图、构建日志或版本报告。
