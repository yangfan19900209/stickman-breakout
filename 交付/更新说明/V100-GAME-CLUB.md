# 1.0.0 游戏圈入口 · 2026-11-13

微信小游戏首页与暂停菜单新增“游戏圈”。点击后由微信原生组件打开当前小游戏的游戏圈首页，不需要开发者另填 openlink。网页保留原有菜单。

## 实现范围

- 使用 `wx.createGameClubButton` 的文字按钮，首页和两关暂停菜单共用一个实例；不提供 `openlink`，不读取用户游戏圈活跃数据。
- 战斗、章节加载、竖屏提示和切到后台时隐藏；回到前台只恢复符合条件的菜单入口。暂停期间打开游戏圈，返回后仍保持暂停，玩家主动点击“继续突围”。
- 打开请求及前后台切换清理按键、触摸和积累时间；销毁组件时解绑回调并销毁原生按钮。点击计数只表示请求，不表示微信页面打开成功。
- 按当前窗口逻辑像素定位，跟随菜单布局和屏幕尺寸，不乘设备像素比。复用已有按钮图片作为兼容入口，未新增游戏美术资源。
- 旧微信没有该接口时显示更新提示；创建失败显示重试提示。原生按钮点击透传到游戏热区时不重复弹出错误。

入口不涉及发帖、分享、奖励任务或用户数据授权。两关开放范围、战斗参数、关卡与原画均保留。

## 导入和真机检查

使用微信开发者工具导入 [wechatgame](../版本/1.0.0-game-club/wechatgame) 文件夹，AppID 沿用项目的 `wx7d2aae02691fc088`。ZIP 为 [游戏圈测试包](../版本/1.0.0-game-club/线条突围-微信小游戏-1.0.0-游戏圈.zip)。

手机横屏确认：首页点击“游戏圈”能打开本游戏社区；返回后开始第一关，暂停后再次进入游戏圈；返回仍暂停且没有持续开火或移动。第二关暂停菜单执行相同步骤；战斗、竖屏和章节加载时不应残留原生按钮。

后续需要直达指定帖子或话题时，再从微信公众平台“游戏能力地图 → 游戏圈”的基础设置或帖子/话题列表取得对应 openlink；它不是浏览器地址栏里的后台网址。本次首页入口无需这项配置。
