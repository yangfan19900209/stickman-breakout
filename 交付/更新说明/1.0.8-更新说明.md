# 线条突围 1.0.8

正式交付日期：2026-11-14。开放第一关与第二关，第三关样段继续关闭。本版本收录1.0.7开发期间确认的改动，正式目录统一为 `交付/版本/1.0.8/`。

## 两关战斗与伤害

| 项目 | 1.0.8配置 |
| --- | --- |
| 小Boss | 两关均为70血 |
| 大Boss | 第一关120血、第二关140血；每场各只召唤一批2名增援 |
| 玩家打Boss | 普通子弹／鱼叉2血、声波3血、火箭／鱼雷5血 |
| 玩家打普通敌人 | 普通子弹／鱼叉1血、声波2血、火箭与近战斩杀 |
| 敌人打玩家 | 普通枪弹／鱼叉与声波1血，火箭／鱼雷2血 |

第一关箱子尺寸统一，新增3个炮筒，分别位于机械阵地、运输栈道与封锁哨线入口。固定普通敌人35名，含Boss共37个，计增援最多39个。

第二关普通鱼叉、声波潜水兵每轮只发一枚，完成下一轮完整预警后才再攻击。轮间休息1.4秒，整组结束后至少休息2秒，换高度和重新瞄准形成不同方向。炮筒改为三方向追踪火箭。玩家鱼叉／声波／鱼雷间隔为0.36／0.43／0.80秒，普通潜水兵更早识别来弹并能侧向或斜向闪避，仍受地形与冷却限制。

10条掠食鱼的游动速度提高到150、扑咬速度740，追击范围820、扑咬距离560；预警0.60秒、恢复1秒。4处敌对水草改为装饰，新增4只3血移动攻击水母。第二关固定普通敌人40名，含Boss、锚雷共45个目标，计增援最多47个。

## 第二关Boss与表现

- 小潜艇减少周围障碍，保留鱼雷、移动声波、俯冲、扇形声波与冲刺五种行动。
- 大潜艇取消向外扩散的曲线扇形圆弧，保留定向激光和直线扫射。声波每轮3枚、每招2轮，轮间0.75秒，相邻弹道约27.5度，两轮方向一致，留出可躲避间隙。招式休息按阶段缩短为0.35／0.28／0.22秒。
- 近距离可向其他方向锁定敌人；声波表现为侧面重叠、依次放大的三个环；火箭／鱼雷带适度追踪。

## 补给与地标说明

火箭和鱼雷均为8发。两关小Boss前的弹药箱提前，箱后保留一波普通敌人。第二关小Boss前血包提前到第一块沉船甲板右端，进入激活范围前可领取；第一关小Boss前血包也位于激活范围之外，油桶靠近坦克。

取消第一关封锁哨线末尾血包，以及第二关水草暗礁末尾、海沟末尾血包。取消4名普通鱼雷潜水兵的掉落，第二关鱼雷仅由3个固定箱提供；声波枪全关仅两处获取。第一关最多9件补给，第二关最多12件，条件血包仍按低血量生成。

完整敌人数量、血量、血包和道具位置见[按地标阅读的配置说明](../../开发计划/关卡/道具清单/两关配置说明-20261114.html)及[文字版](../../开发计划/关卡/道具清单/两关配置说明-20261114.md)。

## 音乐、复活和功能

第一关采用复古风格《土耳其进行曲》，第二关采用《卡农》，普通区域80 BPM、Boss战120 BPM；补全敌人和Boss攻击音效，取消脚步声。

每条完整激励视频领取一次复活，每关最多10次，领取后由玩家点击继续；取消或失败不发放。个人纪录、普通分享、推荐、游戏圈和通关选关保留。好友榜暂时隐藏，等待账号前置条件与权限准备。

Mac命令行开发、构建、固定打包入口及验证记录随源码提交。1.0.7的12个开发和诊断目录已归入[历史测试包索引](../版本/1.0.7/README.md)，文件内容与历史清单保持不变。
