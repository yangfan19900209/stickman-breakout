# 好友榜原生授权测试包

版本 1.0.7；2026-11-14 本地修复包，未上传、送审或发布。

1. 微信开发者工具导入本目录下的 `wechatgame/`，或解压 ZIP 后导入其中同名目录。
2. 重新编译后生成预览，用真机进入“微信好友榜”，点击“查看好友榜”。如已有错误，点击“重试连接”。
3. 首次需要隐私同意时使用微信原生弹窗；同意后继续朋友信息授权。已授权可能直接加载。明确拒绝朋友信息权限后才显示“打开授权设置”。
4. 如果仍出现“好友榜服务暂未就绪”，在真机调试控制台筛选 `[好友榜]`，记录 stage、errno、message；此时需据真实错误核对后台声明或接口能力，不能仅凭这条归类文案判断原因。
